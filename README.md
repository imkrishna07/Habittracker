## About Still

Still is a minimalist habit tracker built to help you create better routines, maintain consistency, and understand your progress over time.

Rather than overwhelming you with unnecessary features, Still focuses on a clean interface and the essential tools needed to build lasting habits.

## Features

- **Daily Habit Tracking** — Mark habits complete or incomplete for any supported date.
- **Backdated Tracking** — Review previous days and update historical completion records.
- **Streak Tracking** — Monitor current and longest streaks.
- **Activity Heatmap** — Visualize your consistency over time.
- **Insights & Statistics** — Understand completion rates and overall progress.
- **Individual Habit Analytics** — Explore each habit's statistics, trends, streaks, and history.
- **Habit Management** — Create, edit, and delete habits.
- **Data Backup & Restore** — Export and import habit data using JSON.
- **Minimalist Interface** — A clean, distraction-free experience.
- **Local Data Storage** — Use the app without creating an account.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPO_URL
```

**2. Navigate into the project directory**

```bash
cd Habittracker
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Data & Privacy

Still uses browser local storage to persist habit data.

- No account is required.
- Data is tied to the browser and website origin where it was created.
- Data does not automatically sync across devices or browsers.
- Clearing browser storage may remove locally stored data.
- Export your data regularly using the JSON backup feature.
